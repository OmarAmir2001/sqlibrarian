PostgreSQL database of one university student's records.
Rows are already limited to the student asking: never filter by student_id.
The current term is the row of terms where is_current is true.

TABLE terms: Academic terms (semesters). Each year has a fall and a spring term, and sometimes a short summer term.
  term_id INT PK: Term number; a higher number is a later term.
  year INT: Calendar year the term starts in, e.g. 2026 for fall 2026 and 2027 for spring 2027.
  season TEXT: Which part of the year: 'fall', 'spring' or 'summer'.
  is_current BOOL: True only for the term running now; "this term" means the row where is_current is true.

TABLE courses: Every course in the Computer Science (CS) and Information Systems (IS) study plans.
  course_code TEXT PK: Course code: department letters, a space, then three digits, e.g. 'CS 201'. CS = computer science, IS = information systems, BS = basic sciences (maths, physics), H = humanities. The first digit is the course level.
  title_en TEXT: Course name in English, e.g. 'Data Structures'.
  title_ar TEXT: Course name in Arabic, e.g. 'هياكل البيانات'.
  credit_hours INT: Credit hours the course is worth: 3 for most courses, 2 for humanities (H) courses.
  level INT: Course level from 1 to 4 (first digit of the code); level 1 courses are usually taken in the first year.
  program TEXT: Which study plan the course belongs to: 'CS', 'IS' or 'both'.
  is_required BOOL: True if every student in the program must pass it; false if it is an elective the student may choose.
  min_passed_hours INT: Credit hours a student must have passed before taking the course; 0 for most courses, 95 for graduation project 1.

TABLE prerequisites: Courses that must be passed before another course can be taken. A course with no rows here has no prerequisite course.
  course_code TEXT PK -> courses.course_code: The course that has the prerequisite.
  required_course_code TEXT PK -> courses.course_code: The course that must be passed first.

TABLE credit_rules: Most credit hours a student may register in one term, depending on cumulative GPA. A new student in their first term may register up to 21 hours. The minimum in a regular term is 9 hours.
  term_type TEXT PK: 'regular' for fall and spring terms, 'summer' for the summer term.
  gpa_from NUMERIC PK: Lowest cumulative GPA of this band (included).
  gpa_to NUMERIC: Upper end of this band (not included): the rule applies when gpa_from <= GPA < gpa_to. The top band ends at 4.01 so a GPA of exactly 4.00 fits.
  max_credit_hours INT: Most credit hours allowed in one term for a GPA in this band.

TABLE grading_scale: How a total mark out of 100 becomes a letter grade and grade points. F (below 50) is a fail; every other letter is a pass.
  letter_grade TEXT PK: Letter grade, from 'A+' (best) down to 'F' (fail).
  min_total NUMERIC: Lowest total mark out of 100 that earns this letter grade.
  points NUMERIC: Grade points for this letter, from 4.0 for A+ to 0 for F; used to compute the GPA.

TABLE tas: Teaching assistants who act as academic advisors and review students' study plans.
  ta_id INT PK: Teaching assistant ID.
  name TEXT: Teaching assistant's full name.

TABLE students: Students. Rows are already limited to the student asking (or a TA's advisees), so queries never need to filter by student.
  student_id INT PK: Student ID.
  name_ar TEXT: Student's full name in Arabic.
  name_en TEXT: Student's full name in English letters.
  program TEXT: Study program: 'CS' (computer science) or 'IS' (information systems).
  level INT: Year of study, 1 to 4.
  cumulative_gpa NUMERIC: Cumulative GPA from 0.00 to 4.00 over all graded courses so far; empty for a new student with no grades yet.
  advisor_ta_id INT -> tas.ta_id: The teaching assistant who advises this student.

TABLE enrollments: One row per course a student registered in a term, with the marks. A course taken again after failing or to improve the grade has one row per attempt.
  enrollment_id INT PK: Row ID.
  student_id INT -> students.student_id: The student who took the course.
  course_code TEXT -> courses.course_code: The course taken.
  term_id INT -> terms.term_id: The term the course was taken in.
  midterm NUMERIC: Midterm exam mark out of 20; empty until recorded.
  coursework NUMERIC: Coursework mark (assignments, labs, quizzes) out of 20; empty until recorded.
  final NUMERIC: Final exam mark out of 60; empty until recorded.
  total NUMERIC: Total mark out of 100 (midterm + coursework + final, capped for repeated courses); empty until the course is graded.
  letter_grade TEXT -> grading_scale.letter_grade: Letter grade from A+ to F; empty until the course is graded.
  grade_points NUMERIC: Grade points for the letter grade, 0 to 4. Term GPA = SUM(grade_points * credit_hours) / SUM(credit_hours) over graded courses.
  status TEXT: 'passed', 'failed', 'in_progress' (this term, no grade yet), 'withdrawn' or 'incomplete'. Only passed and failed rows count in the GPA.

TABLE plans: A student's plan of courses for an upcoming term, sent to their advisor for approval.
  plan_id INT PK: Plan ID.
  student_id INT -> students.student_id: The student the plan belongs to.
  term_id INT -> terms.term_id: The term the plan is for (usually the term after the current one).
  created_at TIMESTAMP: When the student sent the plan.
  status TEXT: 'pending' (waiting for the advisor), 'approved' or 'rejected'.
  reviewed_by INT -> tas.ta_id: The teaching assistant who approved or rejected the plan; empty while pending.
  reviewed_at TIMESTAMP: When the plan was approved or rejected; empty while pending.

TABLE plan_courses: The courses listed in each plan.
  plan_id INT PK -> plans.plan_id: The plan.
  course_code TEXT PK -> courses.course_code: A course the student plans to take.
