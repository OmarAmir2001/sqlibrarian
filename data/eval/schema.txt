PostgreSQL database of one university student's records.
Rows are already limited to the student asking: never filter by student_id.
The current term is the row of terms where is_current is true.

TABLE terms: Academic terms. Each year has a fall and a spring term, sometimes a summer term.
  term_id INT PK: Term number; a higher number is a later term.
  year INT: Calendar year the term starts in (spring 2027 has year 2027).
  season TEXT: 'fall', 'spring' or 'summer'.
  is_current BOOL: True only for the term running now ("this term").
  registration_opens DATE: First day of course registration for this term; empty if not announced.
  registration_closes DATE: Last day of registration; it is open when CURRENT_DATE is between the two dates.

TABLE courses: Every course in the Computer Science (CS) and Information Systems (IS) study plans.
  course_code TEXT PK: e.g. 'CS 201'. CS = computer science, IS = information systems, BS = basic sciences, H = humanities.
  title_en TEXT: English name, e.g. 'Data Structures'.
  title_ar TEXT: Arabic name, e.g. 'هياكل البيانات'.
  credit_hours INT: 3 for most courses, 2 for humanities (H).
  level INT: Study-plan year it is placed in, 1 to 4 (not always the first digit of the code).
  semester TEXT: Study-plan term it is placed in: 'fall' or 'spring'.
  program TEXT: Study plan it belongs to: 'CS', 'IS' or 'both'.
  is_required BOOL: True if required in its program; false for an elective.
  min_passed_hours INT: Passed hours needed before taking it: 0, or 96 for graduation project 1.

TABLE prerequisites: Courses that must be passed before another course can be taken.
  course_code TEXT PK -> courses.course_code: The course that has the prerequisite.
  required_course_code TEXT PK -> courses.course_code: The course that must be passed first.

TABLE course_offerings: Courses open for registration in a term; no row means not offered. The next term has no rows until announced.
  term_id INT PK -> terms.term_id
  course_code TEXT PK -> courses.course_code
  graduates_only BOOL: Only graduation candidates may register it.

TABLE registration_policy: Fixed academic rules, one row each.
  rule_key TEXT PK: Rule name: 'min_credit_hours', 'warning_gpa', 'at_risk_consecutive_warnings', 'at_risk_cumulative_warnings', 'dismissal_consecutive_warnings', 'dismissal_cumulative_warnings', 'graduation_hours' or 'max_elective_courses'.
  value NUMERIC: The rule's number, e.g. 9 for min_credit_hours.
  description TEXT

TABLE credit_rules: Most credit hours a student may register in a term, by cumulative GPA. A new student may register 21.
  term_type TEXT PK: 'regular' (fall, spring) or 'summer'.
  gpa_from NUMERIC PK: Band start (included).
  gpa_to NUMERIC: Band end (not included); the top band ends at 4.01.
  max_credit_hours INT: Hours allowed in this band.

TABLE grading_scale: Total mark out of 100 to letter grade and points. F (below 50) fails; other letters pass.
  letter_grade TEXT PK: 'A+' (best) to 'F'.
  min_total NUMERIC: Lowest total for this letter.
  points NUMERIC: Grade points, 4.0 (A+) to 0 (F).

TABLE tas: Teaching assistants; they are the academic advisors.
  ta_id INT PK
  name TEXT: Full name.

TABLE students: Students (only the one asking, or a TA's advisees).
  student_id INT PK
  name_ar TEXT: Full name in Arabic.
  name_en TEXT: Full name in English letters.
  program TEXT: 'CS' or 'IS'.
  level INT: Year of study, 1 to 4.
  cumulative_gpa NUMERIC: Cumulative GPA, 0.00 to 4.00; empty for a new student.
  completed_credit_hours INT: Credit hours passed so far.
  academic_standing TEXT: 'good_standing', 'at_risk' (near dismissal), 'on_probation' (on an improvement plan), 'improvement_plan_previous' or 'dismissed'.
  consecutive_warnings INT: Academic warnings in a row (a fall/spring term ending with GPA below warning_gpa gives one; a term above resets it).
  cumulative_warnings INT: All academic warnings so far.
  graduation_candidate BOOL: Can reach the 135 graduation hours by the end of next term.
  advisor_ta_id INT -> tas.ta_id: The advisor.

TABLE enrollments: One row per course attempt in a term, with marks; a retaken course has one row per attempt.
  enrollment_id INT PK
  student_id INT -> students.student_id
  course_code TEXT -> courses.course_code
  term_id INT -> terms.term_id
  midterm NUMERIC: Out of 20; empty until recorded.
  coursework NUMERIC: Assignments, labs, quizzes, out of 20; empty until recorded.
  final NUMERIC: Final exam, out of 60; empty until recorded.
  total NUMERIC: Out of 100 (capped for retakes); empty until graded.
  letter_grade TEXT -> grading_scale.letter_grade: A+ to F; empty until graded.
  grade_points NUMERIC: 0 to 4. Term GPA = SUM(grade_points * credit_hours) / SUM(credit_hours) over graded courses.
  status TEXT: 'passed', 'failed', 'in_progress' (this term), 'withdrawn' or 'incomplete'. Only passed and failed count in the GPA.

TABLE excuses: Approved excuses: time off that does not count against the student.
  excuse_id INT PK
  student_id INT -> students.student_id
  academic_year TEXT: e.g. '2024/2025' (fall 2024 and spring 2025).
  excuse_type TEXT: 'term_excuse' (the spring term), 'year_excuse' or 'suspension' (enrollment suspended for the year).

TABLE improvement_plans: Improvement plans for students at risk of dismissal.
  improvement_plan_id INT PK
  student_id INT -> students.student_id
  start_term_id INT -> terms.term_id: Term it started.
  evaluation_term_id INT -> terms.term_id: Term at whose end it is judged.
  outcome TEXT: 'in_progress', 'success' or 'failed'.

TABLE plans: Next-term course plan sent to the advisor for approval.
  plan_id INT PK
  student_id INT -> students.student_id
  term_id INT -> terms.term_id: Term the plan is for (usually next term).
  created_at TIMESTAMP: When it was sent.
  status TEXT: 'pending', 'approved' or 'rejected'.
  reviewed_by INT -> tas.ta_id: TA who reviewed it; empty while pending.
  reviewed_at TIMESTAMP: When reviewed; empty while pending.

TABLE plan_courses: Courses in each plan.
  plan_id INT PK -> plans.plan_id
  course_code TEXT PK -> courses.course_code
